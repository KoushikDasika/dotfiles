# bdui (beads-ui)

`bdui` is the CLI for the `beads-ui` npm package. No user config files — managed entirely by the npm package and per-project `.beads/` directories.

## Installation

Managed via mise (`npm:beads-ui` in `mise/config.toml`). After `mise install`:

```bash
bdui --version
```

Manual install fallback:

```bash
npm install -g beads-ui
```
